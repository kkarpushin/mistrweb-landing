# MISTRweb: лендинг для чешских мастеров

Учебный прототип лендинга. Вымышленная студия делает сайты сантехникам, электрикам и ремонтным бригадам в Чехии, чтобы они не теряли заявки. Компания, контакты и примеры сайтов придуманы.

**Живая версия:** https://kkarpushin.github.io/mistrweb-landing/

## Что посмотреть на странице

- **Первый экран.** Видео с рабочими (сгенерировано в Higgsfield), поверх всплывают карточки новых заявок.
- **Калькулятор потерь.** Ползунки пересчитывают, сколько крон в месяц уходит конкурентам.
- **Демо на двух телефонах.** Клиент заполняет форму на сайте, мастеру приходит уведомление, заявка попадает в список.
- **Анимации появления.** Рамки рисуются из угла, блоки всплывают при прокрутке, на телефоне снизу появляется панель с кнопками.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

## Стек

React 18, TypeScript, Vite 7, Tailwind CSS 3, framer-motion, lucide-react. Шрифты Tektur (заголовки) и Inter Tight (текст) из Google Fonts: в обоих есть кириллица и чешские буквы.

## Где что лежит

```
src/content.ts      все тексты сайта
src/sections/       секции страницы по порядку: Hero, Tapes, Problem, Services, Demo,
                    About, Work, Why, Process, Faq, Contact, Footer
src/components/     общие детали: рамка (Frame), появление при прокрутке (Reveal),
                    кнопки, заголовки секций, видео (ui.tsx)
src/index.css       все анимации (keyframes) и стиль ползунков
public/media/       сжатые видео и картинки
```

## Как переделать под себя

- **Тексты** меняются только в `src/content.ts`. Чтобы перевести сайт на другой язык, достаточно перевести этот файл.
- **Цвета и шрифты** заданы в `tailwind.config.js` и в ссылке на шрифты в `index.html`.
- **Видео и фото** лежат в `public/media/`. Замените файлы, оставив те же имена.

## Своя копия на GitHub Pages

1. Нажмите **Fork**.
2. В своей копии откройте вкладку **Actions** и разрешите запуск workflows.
3. **Settings → Pages → Source:** выберите **GitHub Actions**.
4. Сделайте любой коммит в `main`: сайт соберётся и появится по адресу `https://<ваш-логин>.github.io/mistrweb-landing/`. За сборку отвечает `.github/workflows/deploy.yml`.
